# Запуск Hermes Agent с Ollama и Obsidian: создание локального AI-ассистента с долгосрочной памятью

Hermes Agent — это инструмент, который выводит взаимодействие с LLM на новый уровень, позволяя агенту не просто отвечать на вопросы, но и полноценно работать с вашим хранилищем знаний (Obsidian Vault) в качестве долгосрочной памяти.

## 🛠 Архитектура решения
Система строится на трех китах:
1. **Ollama** — локальный запуск моделей (в нашем случае используется `gemma4:31b-cloud`).
2. **Hermes Agent** — оркестратор, который управляет инструментами, выполняет код и взаимодействует с файловой системой.
3. **Obsidian (hwiki)** — база знаний, которая служит внешней памятью агента.

## 🚀 Пошаговое руководство по настройке

### 1. Конфигурация модели
После установки Hermes Agent необходимо связать его с Ollama. Отредактируйте файл `~/.hermes/config.yaml`.

Пример настройки:
```yaml
model:
  default: "gemma4:31b-cloud"
  provider: "custom"
  base_url: "http://localhost:11434/v1"

custom_providers:
  - name: Ollama-local
    base_url: http://localhost:11434/v1
    model: gemma4:31b-cloud
    models:
      qwen2.5-coder:3b-base: {}
      qwen2.5-coder:1.5b-base: {}
    models_discovered: true
```

### 2. Верификация работы
Проверьте связь агента с моделью через CLI:
```bash
hermes chat -q "Reply with one sentence confirming Hermes works."
```
Если всё настроено верно, агент ответит, используя выбранную модель через локальный API Ollama.

### 3. Интеграция с Obsidian и настройка памяти
Самая интересная часть — превращение ваших заметок в память агента.

**Шаг A: Путь к Vault**
В файле `.env` укажите абсолютный путь к вашему хранилищу:
```env
OBSIDIAN_VAULT_PATH="/mnt/d/<путь>/Мои заметки"
```

**Шаг B: Плагин hwiki**
Установите плагин `hwiki`, который индексирует Markdown-файлы для быстрого поиска:
```bash
hermes plugins install https://github.com/ottosulin/hwiki
hermes memory setup
```
В мастере настройки выберите `hwiki` и укажите путь к папке памяти (например, `Agents/Hermes Agent`).

**Шаг C: Тонкая настройка путей**
Если в пути присутствуют кириллические символы, автоматическая настройка может сработать некорректно. В таком случае отредактируйте `~/.hermes/hwiki.json` вручную, проверив поле `wiki_path`.

## 🎯 Результат: AI с контекстом вашего опыта
После настройки Hermes Agent начинает самостоятельно логировать важные аспекты взаимодействия в папку `wiki/memory`. Теперь агент может:
- Искать информацию по вашим старым заметкам.
- Создавать новые структурированные записи на основе анализа ваших данных.
- Помнить ваши предпочтения и принятые решения между сессиями.

Это превращает обычный чат с LLM в полноценного цифрового двойника, который растет вместе с вашей базой знаний.
