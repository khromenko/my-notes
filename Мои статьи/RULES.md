This is an explicit rule for working with my articles ("мои статьи").
# Directory structure 
for creating articles ("статьи"):
 1. my drafts is in "Мои статьи/my-drafts" - not for agents
 2. draft that is ready for habr are moved/created/copied to "Мои статьи/destinations/habr/drafts" - can use agents and me
 3. drafts that is ready for linkedin - are moved/created/copied in "Мои 
   статьи/destinations/linkedin/drafts"
4. when i do publishing from draft to a live platform i move article/note into parent folder and delete from `draft`, preserving ordinal position in its name ("1 - ...",  
   "2 - ..", etc)
